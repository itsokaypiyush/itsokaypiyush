### Featured Projects

**AgentShield — AI Agent Security Gateway**
A production-oriented security gateway for AI agents combining real-time policy enforcement with on-chain verification.
- Stack: FastAPI, Redis, PostgreSQL, Web3.py (Monad Testnet), React, Vite, TailwindCSS, Docker
- Backend services and smart contracts implemented and verified; containerized deployment and frontend in active development.

**WorldQuant BRAIN — Quantitative Alpha Research**
Independent research building, testing, and submitting predictive alpha factors for systematic equity strategies.
- Designed an automated research pipeline pairing a locally-hosted LLM (via Ollama) with a custom Python orchestration script to accelerate alpha generation.
- Debugged and resolved submission failures across self-correlation, unit consistency, operator access, and signal-quality checks.
- One alpha accepted into production; additional factors carried through extensive iteration on turnover and signal robustness.

**Quantanomics — DeFi and ML Platform**
A decentralized finance platform incorporating machine learning for financial insight generation and strategy development.
- Stack: Python, Vyper, Machine Learning

**Machine Wear Prediction**
Regression-based model for estimating machine wear to support predictive maintenance.
- Stack: Python, Scikit-learn

**Gmail Auto Logout Extension**
Chrome extension that automatically logs out inactive sessions to strengthen account security.
- Stack: JavaScript, Chrome APIs
